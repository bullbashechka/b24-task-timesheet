# PRD: Заполнение табеля 1С из задачи Битрикс24

## Цель

Сотрудник, работающий в 1С со своим табелем (документ «Табель», `Документ.гем_Табель`), добавляет в него строку по задаче Битрикс24. Задачу он выбирает из списка своих задач, время и тип времени указывает в небольшом окне. Содержание, контрагент (по компании CRM задачи) и номер задачи подставляются автоматически.

## Участники и системы

- **Битрикс24 (облако, рабочий портал).** Источник задач, пользователей, компаний CRM и их реквизитов. Функция только читает данные из Битрикс24 и ничего в него не записывает.
- **1С:КА (сервер в офисе).** Здесь находятся табель, физические лица, пользователи и контрагенты. Кнопка и окно заполнения работают в 1С. Доработки выполняются в отдельном расширении `Б24ТабельИзЗадачи` («Б24: табель из задачи») только на встроенном языке 1С (BSL), без HTML/JS, отдельного сервера и приложения Битрикс24. Расширение независимо от расширения `Б24ПрототипЭтап1` (связь заказов клиента с задачами Битрикс24): оно ставится, обновляется и удаляется отдельно и не меняет `Б24ПрототипЭтап1`.
- **Пользователь.** Сотрудник, который входит в 1С под своим пользователем. Пользователь 1С связан с физическим лицом сотрудника, а в карточке физического лица указан e-mail, совпадающий с e-mail его пользователя Битрикс24. Заполнять табель по задаче он может, если является её постановщиком, исполнителем или соисполнителем.

## Фича 1. Кнопка «Заполнить из задачи Б24»

В форме документа «Табель» (`ФормаДокумента`) в командной панели таблицы «Табель», рядом с кнопкой «Добавить», есть кнопка «Заполнить из задачи Б24». Нажатие открывает окно «Заполнить из задачи Битрикс24» (фичи 3 и 4).

Кнопка работает в новом, ещё не записанном табеле и в уже существующем, проведённом или непроведённом. Строка всегда добавляется в табель, открытый в этой форме. Дата строки — дата этого табеля.

Кнопка доступна тогда же, когда доступна кнопка «Добавить» таблицы «Табель»: сейчас это автор табеля и пользователи с полными правами. Когда «Добавить» недоступна, недоступна и «Заполнить из задачи Б24».

## Фича 2. Кто и в какой табель может заполнять

Пользователь определяется по входу в 1С. Его физическое лицо берётся из карточки пользователя 1С. Пользователь Битрикс24 находится по e-mail из карточки этого физического лица (вид контактной информации «Электронная почта»): e-mail сравнивается с e-mail активных пользователей Битрикс24 без учёта регистра и пробелов по краям. Если у физического лица указано несколько адресов, подходит любой из них.

Заполнять из задачи можно только свой табель: сотрудник, указанный в табеле, должен совпадать с физическим лицом текущего пользователя 1С.

При нажатии кнопки 1С выполняет проверки в порядке, указанном в таблице: сначала проверки в 1С, затем обращения к Битрикс24. Если проверка не пройдена, окно открывается без списка задач и полей: в нём только сообщение и кнопка «Закрыть». Табель не меняется.

| Ситуация | Сообщение |
|---|---|
| Адрес вебхука не указан в настройках | «Не настроено подключение к Битрикс24. Обратитесь к администратору» |
| В табеле не указан сотрудник | «Сначала укажите сотрудника в табеле» |
| Пользователь 1С не связан с физическим лицом | «Ваш пользователь 1С не связан с физическим лицом. Обратитесь к администратору» |
| В табеле указан другой сотрудник | «Заполнять из задачи Битрикс24 можно только свой табель» |
| В карточке физического лица не указан e-mail | «В карточке физического лица ‹ФИО› не указан e-mail. Обратитесь к администратору» |
| Битрикс24 не отвечает | «Битрикс24 недоступен. Попробуйте позже» |
| Битрикс24 отклоняет адрес вебхука | «Не настроено подключение к Битрикс24. Обратитесь к администратору» |
| В Битрикс24 нет активного пользователя с таким e-mail | «В Битрикс24 нет пользователя с e-mail ‹e-mail›. Обратитесь к администратору» |

Выбрать можно только задачу, в которой пользователь — постановщик, исполнитель или соисполнитель. Статус задачи не важен: строку можно добавить и по завершённой задаче. Если по номеру или ссылке (фича 3) найдена задача, в которой пользователь не участвует в этих ролях, например является только наблюдателем, в окне показывается сообщение «Заполнять табель по задаче могут только постановщик, исполнитель и соисполнители», а кнопка «Добавить в табель» недоступна.

## Фича 3. Окно: выбор задачи

Окно называется «Заполнить из задачи Битрикс24». Верхняя часть окна — «Задача». Пока 1С загружает задачи из Битрикс24, в окне показывается «Загрузка задач из Битрикс24…».

**Список задач.** В списке находятся задачи, где пользователь — постановщик, исполнитель или соисполнитель: все незавершённые и завершённые не раньше чем за 30 дней до даты табеля. Завершённой считается задача в статусе «Завершена». Задачи в статусах «Ждёт контроля» и «Отложена» считаются незавершёнными. Под списком написано: «Незавершённые задачи и задачи, завершённые с ‹дата›, где вы постановщик, исполнитель или соисполнитель», где ‹дата› — дата табеля минус 30 дней.

| Колонка | Содержимое |
|---|---|
| № | Номер задачи |
| Задача | Название задачи |
| Моя роль | Постановщик, исполнитель или соисполнитель; если ролей несколько — все через запятую |
| Крайний срок | Дата крайнего срока или «без срока» |
| Статус | Статус задачи в Битрикс24 |
| Компания CRM | Название компании из «Элементов CRM»; «—», если компании нет; «‹N› компании», если их несколько |
| Активность | Дата и время последней активности в задаче |

**Сортировка.** Над списком три переключателя: «По активности» (по умолчанию, сначала задачи с самой свежей активностью), «По крайнему сроку» (сначала ближайший срок, задачи без срока в конце) и «По номеру» (сначала задачи с большим номером).

**Поиск.** Поле «Поиск по номеру или названию» оставляет в списке задачи, у которых номер или название содержит введённый текст, без учёта регистра. Если ничего не найдено, в списке написано «Ничего не найдено. Введите номер или ссылку на задачу.»

**Номер или ссылка.** В поле «или номер / ссылка на задачу» можно ввести номер задачи или вставить ссылку на карточку задачи, скопированную из Битрикс24. Найденная задача выбирается, даже если её нет в списке (например, завершена раньше, чем за 30 дней до даты табеля). На неё действуют правила фичи 2. Если задачи с таким номером нет, показывается «Задача №‹номер› не найдена в Битрикс24». Если введено не число и не ссылка на задачу, показывается «Введите номер задачи или ссылку на задачу Битрикс24».

**Выбор задачи.** Задача выбирается щелчком по строке списка. При открытии окна задача не выбрана. Выбранная строка подсвечена, внизу окна написано «Выбрана задача №‹номер›». При выборе задачи поле «Содержание» заполняется её названием, а 1С определяет контрагента (фича 6). При выборе другой задачи «Содержание» заменяется её названием, даже если сотрудник его изменил.

## Фича 4. Окно: поля строки табеля

Нижняя часть окна называется «Строка табеля за ‹дата табеля›». Дата в окне не выбирается: это дата открытого табеля.

| Поле | Значение по умолчанию | Правила |
|---|---|---|
| Время начала | Время окончания строки табеля с самым поздним временем начала. Если в табеле нет строк — 09:00. Если у этой строки не указано время окончания — пусто | Обязательное. Выбирается с шагом 5 минут |
| Время окончания | Пусто | Необязательное. Выбирается с шагом 5 минут, должно быть позже времени начала |
| Тип времени | «Клиент (УД)» | Выпадающий список типов времени «Клиент» и «Офис» из 1С |
| Содержание | Название выбранной задачи | Свободный текст, можно изменить или очистить |
| Контрагент | Определяется по фиче 6 | Только для просмотра |

В списке типов времени — значения перечисления «Типы времени», название которых начинается с «Клиент» или «Офис», в порядке перечисления, кроме «Офис (командировка)» и «Офис (собрания)»: при этих типах табель не допускает контрагента. Типы «Обед», «Дорога (…)», «Пропуск (…)», «Офис (командировка)» и «Офис (собрания)» в окне не выбираются.

Если контрагент найден, показано его наименование и пометка «найден в 1С по БИН ‹номер›». Если не найден, вместо наименования показан текст причины из фичи 6.

Внизу окна две кнопки: «Добавить в табель» и «Отмена». «Отмена» закрывает окно, табель не меняется.

Если время начала и окончания пересекается с временем другой строки табеля, под временем показывается предупреждение «Пересекается со строкой №‹номер› (‹начало›–‹окончание›)» с первой такой строкой. Кнопка «Добавить в табель» при этом доступна: сотрудник решает сам.

Кнопка «Добавить в табель» недоступна, пока не выбрана задача, не указано время начала или время окончания не позже времени начала. У ошибочного поля показывается подсказка: «Укажите время начала» или «Время окончания должно быть позже времени начала».

## Фича 5. Добавление строки в табель

Нажатие «Добавить в табель» добавляет новую строку в таблицу «Табель» открытого документа. Строки таблицы сортируются по времени начала, как перед добавлением строки кнопкой «Добавить», и новая строка встаёт на своё место. Окно закрывается, новая строка становится текущей. Если контрагент не найден, курсор встаёт в поле «Контрагент» новой строки и открывается выбор контрагента.

| Поле строки | Значение |
|---|---|
| Контрагент | Найденный по фиче 6. Если не найден, поле пустое |
| Тип времени | Выбранный в окне |
| Время нач. | Указанное в окне |
| Время кон. | Указанное в окне. Если не указано, поле пустое |
| Содержание | Указанное в окне |
| ID Б24 | Номер задачи Битрикс24 |

Тип ПП не заполняется. Если время окончания указано, все расчётные поля строки (Факт, Норма, К оплате, Зарплата и другие) и итог «Всего зарплата» рассчитываются так же, как при ручном вводе времени в табеле. Если время окончания не указано, сотрудник позже вводит его в строке сам, и табель выполняет тот же расчёт. Остальные поля строки («Печать», «Проезд», «Заметки» и другие) получают те же значения, что у строки, добавленной кнопкой «Добавить».

Строка не записывается автоматически: табель становится изменённым, и сотрудник записывает или проводит его как обычно. Если закрыть табель без записи, строка не сохранится.

Каждое нажатие «Добавить в табель» добавляет новую строку. Повторное заполнение по той же задаче добавляет ещё одну строку, а существующие строки не меняются.

## Фича 6. Контрагент из компании CRM

Контрагент определяется только по компании, привязанной к задаче в поле «Элементы CRM». Название задачи и название компании для поиска контрагента не используются.

**Какая компания берётся.** Если в «Элементах CRM» привязана ровно одна компания, берётся она. Если привязано несколько компаний, контрагент не определяется. Если компании нет, а привязаны только сделки, контакты или другие элементы CRM, контрагент не определяется: компания из сделки или контакта не подтягивается. Компания, удалённая из CRM, но оставшаяся привязанной к задаче, считается отсутствующей.

**Сопоставление с контрагентом 1С.** Номер берётся из реквизитов компании в Битрикс24: из реквизита берётся первое заполненное из полей БИН (`RQ_BIN`), ИИН (`RQ_IIN`) и ИНН (`RQ_INN`). Так поддерживаются юрлица, индивидуальные предприниматели и компании с российским ИНН. Если у компании несколько реквизитов, используется первый (в порядке, в котором они показаны в карточке компании), где заполнено одно из этих полей. Номер сравнивается с полем «БИН/ИИН» (`ИНН`) контрагента в 1С, перед сравнением пробелы убираются с обеих сторон. Контрагенты, помеченные на удаление, не учитываются.

Если найден ровно один контрагент, он подставляется в строку. Если не найдено ни одного или найдено несколько, поле «Контрагент» в строке остаётся пустым, и сотрудник выбирает контрагента в строке табеля сам. Строка добавляется в любом случае.

| Ситуация | Текст в окне |
|---|---|
| В задаче нет компании CRM | «В задаче не указана компания CRM — выберите контрагента вручную» |
| В задаче несколько компаний CRM | «В задаче несколько компаний CRM — выберите контрагента вручную» |
| У компании в реквизитах не заполнен ни БИН, ни ИИН, ни ИНН | «У компании «‹название›» не заполнен БИН — выберите контрагента вручную» |
| В 1С нет контрагента с таким БИН | «Контрагент с БИН ‹номер› не найден в 1С — выберите контрагента вручную» |
| В 1С несколько контрагентов с таким БИН | «В 1С несколько контрагентов с БИН ‹номер› — выберите нужного вручную» |

## Фича 7. Колонка «ID Б24» в табеле

В табличную часть «Табель» документа `гем_Табель` добавляется колонка «ID Б24» — строка длиной 20 символов. Колонка добавляется через расширение `Б24ТабельИзЗадачи`, видна в основной форме документа (`ФормаДокумента`) и редактируется сотрудником. При заполнении из задачи в неё записывается номер задачи. В строках, добавленных вручную, колонка пустая.

## Фича 8. Настройки интеграции и режим тестирования

В 1С есть форма «Настройки интеграции с Битрикс24». Её открывают пользователи с полными правами. В ней задаются:

- **Адрес входящего вебхука Битрикс24.** Вебхук создаёт администратор Битрикс24 с правами «Задачи», «CRM», «Пользователи» и «Рабочие группы». Последнее право нужно, чтобы показать название проекта в режиме тестирования. После сохранения адрес в форме не показывается целиком.
- **Режим тестирования** — флажок.
- **Проект для тестирования** — ID проекта Битрикс24.

Вебхук работает с правами создавшего его администратора: этот пользователь должен видеть все задачи и компании CRM. Если его отключить или лишить прав администратора, подключение перестанет работать, и 1С будет показывать «Не настроено подключение к Битрикс24. Обратитесь к администратору».

Когда режим тестирования включён:
- в списке задач показываются только задачи проекта для тестирования;
- над списком написано «Режим тестирования: показаны только задачи проекта «‹название проекта›»»;
- при вводе номера или ссылки на задачу другого проекта показывается «В режиме тестирования доступны только задачи проекта «‹название проекта›»», а кнопка «Добавить в табель» недоступна. Эта проверка выполняется раньше проверки роли (фича 2).

На демо-базе КА режим тестирования включён, проектом для тестирования указан «[ТЕСТ] Табель из задачи». В рабочей КА режим тестирования выключен.

## Связь с Битрикс24 и безопасность

- 1С обращается к Битрикс24 по HTTPS через входящий вебхук из настроек (фича 8). Серверу 1С нужен исходящий доступ к порталу Битрикс24. Публиковать 1С на веб-сервере и устанавливать приложение в Битрикс24 не требуется.
- Функция только читает данные Битрикс24: пользователей, задачи, компании CRM и их реквизиты. В Битрикс24 ничего не записывается.
- Адрес вебхука хранится в безопасном хранилище 1С. Он не попадает в журнал регистрации, в тексты сообщений и в формы, кроме формы настроек.
- Обращения к Битрикс24 и ошибки записываются в журнал регистрации без адреса вебхука.
- Битрикс24 считается недоступным, если он не ответил за 30 секунд или вернул ошибку сервера.
- Если Битрикс24 не отвечает, когда окно уже открыто (загрузка списка, поиск по номеру или ссылке, выбор задачи), в окне показывается «Битрикс24 недоступен. Попробуйте позже». Окно остаётся открытым, введённые данные сохраняются.

## Тестовые данные и приёмка

Разработка ведётся на копии демо-базы КА у разработчика. Приёмка проходит на демо-базе КА на сервере офиса в режиме тестирования; функциональность проверяют реальные сотрудники. В Битрикс24 разработка и приёмка ведутся на рабочем портале с тестовыми компаниями и задачами. После приёмки расширение устанавливается в рабочую КА с предварительной резервной копией, в настройках указывается рабочий вебхук и выключается режим тестирования. Сотрудники, которые будут пользоваться функцией, указывают e-mail в Битрикс24 и в карточке своего физического лица в рабочей КА.

**Правила для тестовых данных:**

- Название каждой тестовой компании и задачи начинается с префикса «[ТЕСТ]», например «[ТЕСТ] АВИКА». На поиск контрагента префикс не влияет.
- Обмен CRM 1С ↔ Битрикс24 в разработке и приёмке не участвует.
- Тестовые задачи ставятся в проект «[ТЕСТ] Табель из задачи». Участники проекта — только проверяющие.
- У проверяющих пользователи 1С на демо-базе КА связаны с их физическими лицами, а e-mail в карточке физического лица совпадает с e-mail в Битрикс24.
- На время разработки используется e-mail разработчика из переменной `TEST_USER_EMAIL` в файле `.env` (в git не попадает, шаблон — `.env.example`). Он указан у пользователя Битрикс24 разработчика и в карточке физического лица пользователя, под которым разработчик входит в свою копию демо-базы КА.
- Тестовые данные создаются через REST по входящему вебхуку для разработки с правами «CRM», «Задачи», «Пользователи» и «Рабочие группы». Перед внедрением в рабочую КА этот вебхук перевыпускается.
- После приёмки тестовые компании, задачи и проект удаляются из Битрикс24, а строки табеля с номерами тестовых задач удаляются из демо-базы КА.

**Набор тестовых компаний.** У каждой компании в реквизитах заполнен БИН или ИИН контрагента из КА, если в таблице не сказано иное. Клиенты компании только казахстанские, поэтому компания с российским ИНН вживую не создаётся: поиск по полю «ИНН» проверяется автотестом.

| Компания | Реквизиты | Ожидаемый результат |
|---|---|---|
| Компания-юрлицо | БИН контрагента КА | Контрагент подставляется |
| Компания-ИП | ИИН контрагента КА | Контрагент подставляется |
| Компания с двумя реквизитами | Первые реквизиты без БИН, вторые с БИН контрагента КА | Контрагент подставляется по вторым реквизитам |
| Компания без реквизитов | — | «Не заполнен БИН», контрагент пустой |
| Компания с несуществующим БИН | БИН, которого нет в КА | «Не найден в 1С», контрагент пустой |
| Компания с БИН дубля | БИН, который в КА есть у двух контрагентов | «Несколько контрагентов», контрагент пустой |

**Набор тестовых задач.** В проекте «[ТЕСТ] Табель из задачи» к каждой компании из таблицы привязана своя задача, одна из этих задач завершена. Дополнительно в проекте есть задача с двумя привязанными компаниями (ожидается «несколько компаний CRM»), задача без компании (ожидается «не указана компания CRM») и задача, в которой проверяющий только наблюдатель. Вне проекта есть одна задача, в которой проверяющий — исполнитель.

**Сценарии приёмки:**

- **С1.** Сотрудник открывает свой табель, нажимает «Заполнить из задачи Б24» и выбирает задачу из списка. В табеле появляется строка с контрагентом, типом времени, временем, содержанием и номером задачи в «ID Б24». Табель записывается и проводится как обычно.
- **С2.** Задача выбирается по номеру и по ссылке на карточку задачи. Несуществующий номер и текст, который не является номером или ссылкой, дают соответствующие сообщения.
- **С3.** Поиск по номеру и по части названия; сортировка по активности, по крайнему сроку и по номеру. Завершённая тестовая задача есть в списке табеля за сегодня и отсутствует в списке табеля за дату позже даты её завершения плюс 30 дней.
- **С4.** Повторное заполнение по той же задаче добавляет вторую строку, первая не меняется.
- **С5.** Заполнение с временем окончания (Факт, Норма, К оплате, Зарплата и итог «Всего зарплата» совпадают с ручным вводом) и без него.
- **С6.** Все 6 компаний и задачи с двумя компаниями и без компании дают ожидаемый результат по контрагенту.
- **С7.** Задача, где проверяющий только наблюдатель, введённая по номеру: показывается сообщение о правах, добавить строку нельзя.
- **С8.** Чужой табель и табель без сотрудника: показываются соответствующие сообщения, окно не даёт заполнить строку. В табеле, открытом только для просмотра, кнопка недоступна.
- **С9.** Пользователь 1С без физического лица, физическое лицо без e-mail и e-mail, которого нет в Битрикс24: показываются соответствующие сообщения.
- **С10.** Режим тестирования: в списке только задачи проекта «[ТЕСТ] Табель из задачи»; задача вне проекта, введённая по номеру, не принимается.
- **С11.** Неверный адрес вебхука и отсутствие связи с Битрикс24: показываются соответствующие сообщения, введённые данные в окне сохраняются.
- **С12.** Ошибки ввода: без времени начала и с временем окончания не позже начала кнопка «Добавить в табель» недоступна, у поля показывается подсказка.
- **С13.** Колонка «ID Б24» видна и редактируется в форме табеля; в строках, добавленных вручную, она пустая.
- **С14.** В списке типов времени только типы «Клиент» и «Офис», кроме «Офис (командировка)» и «Офис (собрания)»; по умолчанию выбран «Клиент (УД)».
- **С15.** Время начала по умолчанию равно окончанию самой поздней строки табеля, в пустом табеле — 09:00, при самой поздней строке без окончания — пусто. Добавленная строка встаёт на место по времени начала. Пересечение с другой строкой даёт предупреждение, но строку добавить можно. Если контрагент не найден, после добавления курсор стоит в поле «Контрагент» новой строки.

## Вне рамок

- Кнопка и окно заполнения в интерфейсе Битрикс24.
- Запись в Битрикс24: затраченного времени, комментариев, статуса задачи.
- Заполнение чужого табеля.
- Добавление нескольких строк за одно нажатие.
- Изменение существующих строк табеля.
- Добавление строки в табель за другую дату: строка добавляется только в открытый табель.
- Выбор контрагента в окне: если контрагент не найден, его выбирают в строке табеля.
- Заполнение поля «Тип ПП».
- Выбор типов времени «Обед», «Дорога (…)», «Пропуск (…)», «Офис (командировка)» и «Офис (собрания)» в окне: их указывают в строке табеля.
